Info & Settings
How This Test Works

SpeedLab uses Cloudflare's global network to perform real file downloads and uploads, measuring your connection speed in real-time. No simulation or demo data is used — every number comes from your actual network connection.

What's Measured
  • Ping (Latency): Round-trip time to send a request to the server
  • Jitter: Variation in time between multiple ping samples
  • Download: Speed of downloading real files from Cloudflare servers
  • Upload: Speed of uploading real data from your device to the server
  • IP & ISP: Your current network information from public APIs
Limitations (Browser-based App)

Since this is a browser/PWA app, certain features that require OS-level permissions are not possible without a native Android/iOS app:

  • Live speed display in status bar notifications
  • Background monitoring service
  • WiFi vs mobile data usage tracking
Privacy

Your test history is stored only on your device (LocalStorage) — nothing is sent to or stored on any server.

Test Server Selection

The nearest Cloudflare edge server is automatically selected.
